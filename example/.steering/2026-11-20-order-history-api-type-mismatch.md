## 実レスポンスの観測

100件取得した。

- `orderId`: 全件が文字列。数値で返るものは0件。
- `totalPrice`: 数値。仕様書どおり。
- `canceledAt`: 未キャンセルの注文は`null`。仕様書に`null`の記載はない。

前回の流れと同じく、型の不一致が1項目に限らない可能性がある。観測は全項目で行った。
