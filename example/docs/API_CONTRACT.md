# 会員一覧API 契約

## 1. 基本

- `GET /members`
- 認証: ベアラートークンを `Authorization` ヘッダに付与する。
- 提供元は別会社。APIの修正は画面側ではできない。

## 2. レスポンスの項目

| 項目 | 型 | 備考 |
|---|---|---|
| `memberId` | 文字列 | 先頭ゼロを含む。数値として扱わない |
| `name` | 文字列 | |
| `points` | 数値または `null` | `null` はポイント制度の未加入を意味する |

## 3. 境界での扱い

- 受け取ったJSONは、画面に渡す前に検証する。
- 想定外の型はエラーとして扱い、変換して吸収しない。
- 検証エラーでも、画面全体を止めない。該当する会員の行だけをエラー表示にし、エラーの内容をログに記録する。
